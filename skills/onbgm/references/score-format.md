# onbgm 乐谱格式参考

本文档和 `onbgm schema` 输出的 JSON Schema 不一致时，以 schema 为准。目前只支持 4/4 拍。

## 最小完整示例

```yaml
title: Morning Coffee          # 曲名，写在顶层
meta:
  bpm: 96
  key: C major                 # 仅作记录
  loop: true                   # true 输出 loop.wav；默认 false，输出 song.wav

sections:                      # 按播放顺序
  - { name: intro, bars: 4, energy: 0.3 }
  - { name: main,  bars: 8, energy: "0.5->0.8" }   # 段内渐强

harmony:                       # 每个段落都要有一行
  intro: "Cmaj7 | Am7 | Dm7 | G7"
  main:  "Cmaj7 | Am7 | Dm7 | G7"                  # 小节数能整除段落时会自动重复

tracks:
  keys:
    sound: epiano
    texture: comp
    rhythm: "x--- --x- ---- ----"
  lead:
    sound: vibraphone
    notes:                     # 写了 notes 就默认是 melody 织体
      main: "E5/4 G5/4 C6/2 | B5/2 G5/2 | A5/4 F5/4 D5/2 | r/1"
```

## meta

| 字段 | 说明 |
|---|---|
| `bpm` | 数字；或写 `auto`，由 `length` 或某个段落的 `at` 反推速度 |
| `length` | 乐谱时长约束，如 `"1:00"`，配合 `bpm: auto` 使用。不含 `tail`：不循环的曲子输出时长 = `length` + `tail` |
| `key` | 调性，仅作记录 |
| `loop` | `true`：输出首尾无缝的 `loop.wav`；不写或 `false`：输出 `song.wav` |
| `tail` | 仅用于不循环的曲子：乐谱结束后再留几秒余音，如 `2` |
| `seed` | 人性化随机种子，默认 0。修改乐谱时保持不变 |
| `swing` | 摇摆：0.5 平直（默认），0.58 左右是 lo-fi 的晃动感，0.62~0.67 接近三连音的爵士感 |
| `swing_unit` | `16`：十六分音符摇摆（默认）；`8`：八分音符摇摆（爵士、shuffle） |

时间可以写成秒数（`12.5`）或 `"分:秒"`（`"0:32"`）。

## fx

| 字段 | 说明 |
|---|---|
| `lofi` | 0~1。磁带抖动、低通、轻微失真、黑胶底噪 |

## sections

每个段落有三个字段：`name`、`bars`（小节数，正整数）、`energy`（可选，默认 0.5），另外可选 `at`。

- **energy** 写 0~1 的数字，或用 `"0.4->0.9"` 表示段内从 0.4 渐变到 0.9。它影响所有声部的力度和表情，也影响部分织体的密度（例如分解和弦在能量低时只弹四分音符）。
- **at** 表示"这一段必须从这个时间开始"。和 `bpm` 冲突时会报错，并给出几种改法：改速度、保持速度但改前面的小节数（会算出需要几小节），或删掉约束。
  用户要"更快但时间点不变"时，应该按比例增加前面的小节数：新小节数 = 秒数 × 新 BPM ÷ 240。

## harmony

格式是 `{段落名: "和弦 | 和弦 | …"}`：`|` 分隔小节；同一小节写多个和弦（用空格隔开）时，按拍数平分。
写的小节数要等于段落的小节数，或者能整除它（整除时会自动重复）。

和弦写法是"根音 + 类型 + 可选的 /低音"，例如 `C`、`F#m7`、`Bbmaj9`、`D/F#`、`G13`、`A7b9`。
支持的类型有：
- 大三和弦（不写类型）、`m`、`dim`、`aug`、`sus2`、`sus4`
- `6`、`m6`、`7`、`maj7`、`m7`、`m7b5`、`dim7`、`7sus4`
- `add9`、`madd9`、`9`、`maj9`、`m9`、`m11`、`13`、`7b9`、`7#9`、`maj7#11`、`6add9`

## tracks

格式是 `{声部名: {...}}`。所有声部都能用的字段：

| 字段 | 说明 |
|---|---|
| `sound` | 音色，见文末的表 |
| `texture` | 织体，见下文。写了 `notes` 时默认是 `melody` |
| `in` | 出现在哪些段落：`[verse, chorus]` 或 `all`（默认）。旋律声部默认是写了 notes 的那些段 |
| `gain` | 在自动混音结果上再加减的音量（dB），一般不需要 |

一个声部只能用一种织体。想在某一段换写法（比如前面用分解和弦、最后一小节改成柱式和弦收尾），就拆成两个声部，用 `in` 分配段落：

```yaml
piano:     {sound: piano, texture: arpeggio, in: [intro, theme]}
piano_end: {sound: piano, texture: comp, in: [final], rhythm: "x--- ---- ---- ----"}
```
| `by_section` | 某些段落换一套节奏型：`{段落名: {rhythm: …}}` 或 `{段落名: {pattern: …}}`，只用于 groove、bassline、comp、strum。groove 的 pattern 是整套替换：这一段要用的每件鼓都得写上，没写的鼓在这一段不打 |

音量不用你管：伴奏按角色自动定音量；`melody` 在每段自动调到比伴奏略响。

### 旋律记法（melody、line 的 notes）

```yaml
notes:
  verse:  "r/8 A4/8 C5/8 E5/8 D5/4. C5/8 | B4/2~ B4/4 r/4"
  chorus: "G5/4 E5/8 G5/8 r/8 E5/8 D5/4 | …"
```

- 音高写成 `音名[#/b]八度`，`C4` 是中央 C（MIDI 60），如 `F#5`、`Bb3`。
- 时值：`/1` 全音符、`/2` 二分、`/4` 四分、`/8` 八分、`/16` 十六分；加 `.` 是附点（如 `D5/4.`）；`r/4` 是休止。
- 在音符后加 `~`，表示连到下一个同音高的音（如 `B4/2~ B4/4`）。
- 演奏法记号写在时值后面：`'` 是断奏（`D5/16'`），`>` 是重音（`D5/8>`），可以合写（`D5/8.'>`）。
  断奏的实际发声是写的时值的一半（最长半拍），弦乐会改用跳弓（spiccato）采样；重音会让这个音明显更响。
- `|` 分小节，每小节必须正好 4 拍。小节数要等于段落的小节数，或者能整除它。
- 弱起（下一段的旋律提前几个音进入）就写在前一段的 notes 末尾，先用休止填满，再写弱起的音。
- 力度一般不用写：引擎按能量和旋律走向（越高越响一点）自动安排，需要强调的音用 `>`。
- 整个声部都是断奏时，不用每个音都加 `'`，写 `articulation: staccato` 即可（melody、line、bassline 可用）。
  快速的弦乐音型一定要用断奏：长音采样起音慢、释音长，十六分音符会糊成一片。
- `gate` 控制非断奏音的实际发声长度占时值的比例：持续音乐器（弦乐、管乐等）默认 1.0，其他默认 0.95。

### 节奏型记法（groove、bassline、comp、strum）

- 每小节写 8、12、16、24 或 32 个字符，一个字符是一步。16 个字符就是一个字符一个十六分音符；8 个是八分音符；12 个是八分音符三连音。
- 空格只是为了好读，会被忽略。`|` 分小节；小节数少于段落时自动重复，但必须能整除。

| 织体 | 字段 | 字符含义 |
|---|---|---|
| `groove` 鼓组 | `pattern: {鼓件: 节奏型}` | `X` 重音，`x` 普通，`g` 轻声（ghost note），`.` 不打 |
| `bassline` 低音 | `rhythm` | `1 3 5 7 8`：当前和弦的级数（1 是低音，落在 `[low, low+11]` 这个八度内，斜杠和弦取斜杠后的音；3/5/7 在它上方；8 是高八度；没有七音时 7 弹高八度根音），`-` 延长，`.` 休止 |
| `comp` 和弦伴奏 | `rhythm` | `X`/`x` 弹和弦（X 更重），`-` 延长，`.` 休止 |
| `arp` 琶音器 | `rhythm` | 每个 `X`/`x` 弹当前和弦的下一个音，`-` 延长，`.` 休止；`mode` 是 `up` / `down` / `updown`，`range` 是取音的音区（默认 `[60, 84]`）；换和弦时从头开始 |
| `strum` 吉他扫弦 | `pattern` | `D`/`U` 下扫/上扫（上扫只扫高音 4 根弦），`d`/`u` 轻扫，`x` 闷音切音，`.` 让弦继续响 |

和弦变化的规则：
- 延长（`-`）途中换了和弦，会在新和弦上重新起音。
- strum 里的 `.` 会让上一下扫的弦继续响，新和弦要等下一次扫弦才生效。所以每个换和弦的位置都要写一下扫弦。
- 吉他按法由引擎在真实的标准调弦六弦吉他上自动选（G = 320003、D/F# = 200232、F = 133211…）。

鼓件名：`kick rim snare clap hat pedal-hat open-hat tom-low tom-mid tom-high crash ride ride-bell tambourine cowbell conga-high conga-low cabasa shaker`。
只在某一段开头敲一下吊镲，可以在那一段的 `by_section` pattern 里写 `crash: "X... .... .... ...."`，也可以用 `crash` 织体。

### 织体一览

| 织体 | 用途 | 专属字段 |
|---|---|---|
| `melody` | 主旋律，逐音写；自动混音让它比伴奏略响 | `notes`，`gate`（实际长度占时值的比例），`articulation` |
| `line` | 逐音写的伴奏线：walking bass、副旋律、有经过音的低音、弦乐音型；按伴奏定音量 | `notes`，`gate`，`articulation` |
| `arpeggio` | 抒情钢琴分解和弦（1-5-8-9-10…），能量低于 0.35 时只弹四分音符，自动换踏板 | `low`（左手最低音区，默认 36） |
| `pad` | 四声部持续和弦，段内就近进行 | `range`（默认 `[48, 72]`） |
| `comp` | 按节奏型弹和弦，四声部就近进行 | `rhythm`，`range`（默认 `[48, 67]`，垫在旋律下面），`roll`（从低到高拨开的间隔，拍） |
| `arp` | 琶音器：按节奏型、按和弦音自动上下走，科技、电子风格的核心 | `rhythm`，`mode`，`range`，`articulation` |
| `strum` | 吉他扫弦 | `pattern`，`spread`（相邻弦的时间差，秒，默认 0.012） |
| `bassline` | 按级数走的节奏型低音 | `rhythm`，`low`（默认 28），`articulation` |
| `bass-sustain` | 每个和弦一个长音根音 | `low`（默认 28） |
| `bass-pizz` | 拨弦低音：根-根-五-八 | `low`（默认 36） |
| `groove` | 鼓组 | `pattern`，`laid_back`（军鼓/拍手往后拖的拍数，如 0.03） |
| `timpani` | 定音鼓重拍；能量 ≥ 0.8 时第三拍再敲一下。要别的节奏，就另开一个 `sound: timpani` 的 `line` 声部逐音写 | `low`（默认 38），`roll_into: 段落名`（在该段前一小节做渐强滚奏） |
| `crash` | 在 `in` 列出的每个段落开头敲一下吊镲 | — |

## sfx（音效时间线）

和音乐共用一个时钟的合成音效。只做需要和音乐对齐的乐器性、合成类音效，不做拟音和环境音（脚步、开门、雨声这类）。

```yaml
sfx:
  - { type: riser, at: drop, length: 8 }     # 上升音：在 drop 段第一拍戛然而止
  - { type: impact, at: drop, duck: 4 }      # 冲击：从 drop 第一拍开始，同时把音乐压低 4 dB
  - { type: whoosh, at: "0:16" }             # 转场：最响处对准 0:16
  - { type: ding, at: logo, level: 0.5 }     # 提示音：自动弹当时和弦的根音
```

| 字段 | 说明 |
|---|---|
| `type` | 音效类型，见下表 |
| `at` | 对准点：段落名（指该段开头），或时间（`8.5`、`"0:08.5"`） |
| `length` | 长度（拍）。只有长度可变的类型能写 |
| `level` | 音量 0~1，默认 0.8。1 大约和高潮段的音乐一样响 |
| `duck` | 发生时把音乐压低多少 dB，约 0.35 秒内恢复。适合冲击这种需要"让出空间"的时刻 |

不同音效对准 `at` 的方式不同，这是剪辑里的惯例：

| 类型 | 对准方式 | 默认长度 | 用途 |
|---|---|---|---|
| `riser` | 在 `at` **结束** | 8 拍 | 上升音：越来越响，在高潮、drop、产品亮相的一刻戛然而止 |
| `reverse-cymbal` | 在 `at` **结束**（最响） | 4 拍 | 反向镲：段落转换前的经典过门 |
| `whoosh` | 最响处在 `at` | 2 拍 | 转场、镜头切换 |
| `impact` | 从 `at` **开始** | 约 3 秒 | 冲击：画面重点、标题出现 |
| `sub-drop` | 从 `at` 开始 | 4 拍 | 下坠低音：从当时和弦的根音往下滑两个八度 |
| `downlifter` | 从 `at` 开始 | 4 拍 | 下降音：重击之后或段落回落时慢慢消失 |
| `pop` | 从 `at` 开始 | 约 0.15 秒 | 图标、文字弹出，和当时的和弦同调 |
| `ding` | 从 `at` 开始 | 约 0.9 秒 | 提示音（FM 钟声），弹当时和弦的根音 |

- 有音高的音效（`sub-drop`、`pop`、`ding`、上升音里的音调）会自动取当时和弦的根音，和音乐同调。
- 上升音太长、起点会早于乐谱开头时，会报 `sfx_out_of_range`，并在 `fix.length` 里给出能放下的最大长度。
- 写法库里有常用组合：`onbgm catalog --kind sfx`。

合成器音色（由引擎直接合成，不需要下载音源，任何档位都可用）：

| 音色 | 用途 |
|---|---|
| `synth-pluck` | 科技感的拨弦，琶音的首选；自带附点八分延迟 |
| `synth-pad` | 宽厚的合成铺底，慢起慢收 |
| `supersaw` | 电子舞曲的"超级锯齿"和弦，适合高潮的重击 |
| `synth-lead` | 合成器主旋律，带延迟颤音 |
| `synth-bass` | 有起音"嗒"声的合成贝斯 |
| `sub-bass` | 纯净的超低音 |
| `bass-808` | 808 低音：起音时音高下滑，长衰减 |
| `synth-bell` | FM 钟声，适合高音区的旋律或点缀 |
| `fm-epiano` | FM 电钢琴（DX7 风格） |

鼓组：`drums`（标准）、`drums-room`、`drums-jazz`、`drums-brush`（刷子）、`drums-808`、`drums-electronic`、`drums-synth`（合成鼓组，电子风格首选）。

超出音域的音会在报告里给出警告。
