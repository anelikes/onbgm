# 怎么把 BGM 写好

BGM 的任务是托住画面，而不是抢戏。好的 BGM 段落清楚、起伏可预期、在需要的时间点准确地到达。

## 结构和能量

- 先画能量曲线，再写音符。典型的走向是：前奏 0.2–0.4 → 铺垫段渐强（`"0.4->0.8"`）→ 高潮 0.9–1.0 → 回落。能量差越大，起伏越明显。
- 段落长度用 4 或 8 小节，听起来最自然。
- 时间要求交给引擎算：写段落的 `at` 或 `meta.length`，配上 `bpm: auto`。
  例如"20 秒、第 12 秒进副歌"：前面 6 小节加后面 4 小节、`at: "0:12"`，引擎会算出 120 BPM。
- 想让高潮有冲击力，就在高潮之前做一点准备：
  - 前一段渐强；
  - 前一小节加定音鼓滚奏（`roll_into`）；
  - 高潮的第一拍敲吊镲；
  - 最后一个和弦用属和弦（V），比如 D 小调里的 A7。

## 循环和收尾

- **循环曲**（`loop: true`）：最后一个和弦用属和弦（V 或 V7），它会自然地导回开头的主和弦。尾声的能量回落到接近前奏的水平，循环一圈才不突兀。
- **不循环的曲子**需要收尾。引擎没有专门的收尾指令，用写法来做：
  - 最后一小节用主和弦（I），并且只在第一拍起音：comp 写 `"x--- ---- ---- ----"`，strum 写 `"D... .... .... ...."`，bassline 写 `"1--- ---- ---- ----"`；
  - 旋律落在主音上，写成全音符；
  - 鼓在最后一拍的第一下用重音，加 `crash`，之后不再打；
  - 前面一两个和弦用 IV–V 或 ii–V 引到 I，结束感会更强；
  - 设置 `meta.tail: 1.5`~`2`，给余音留出时间。

## 旋律和伴奏的分工

- 旋律要在伴奏的上方。`comp` 默认音区是 48–67，`pad` 是 48–72，所以旋律主要写在 C5（72）以上最清楚。旋律写得低的话，就把伴奏的 `range` 调低。
- 旋律的骨干音落在和弦音上（根音、三音、五音、七音），强拍尤其如此；经过音放在弱拍或短时值上。
- 动机加模进最好记：写一个两小节的乐句，再把它整体上移或下移一级重复。
- 留白：乐句之间写一点休止，比连续不停的旋律更像真人演奏，也更适合当背景。
- 前奏可以用轻一点的乐器先预告主题，高潮时再让主奏乐器完整地奏出来。

## 风格配方

运行 `onbgm example <名字>` 可以拿到完整乐谱。

| 风格 | 示例 | 要点 |
|---|---|---|
| 电影感 / 情绪 | `night_rain_v1` | `arpeggio` 钢琴，`pad`（`strings-slow`）铺底，`bass-sustain`，高潮用 `strings` 唱旋律，加 `timpani`（`roll_into`）和 `crash` |
| lo-fi | `late_study` | 75–85 BPM，`swing: 0.58`，`fx.lofi: 0.6~0.8`，`epiano` 的 `comp` 配爵士和弦（m9、13、7b9），`drums-jazz` 加 `laid_back: 0.03`，颤音琴旋律 |
| 木吉他 vlog | `sunny_walk` | 105–120 BPM，大调 I–V–vi–IV，`strum` 主歌加闷音切音（`x`），副歌扫满；拍手打二、四拍；`shaker` 十六分音符；`glockenspiel` 旋律 |
| 咖啡馆爵士 | `cafe_jazz` | `swing: 0.62` 加 `swing_unit: 8`，每小节 8 步的节奏型；ii–V–I 和弦进行；`drums-brush` 的 ride 加 pedal-hat；`contrabass` 低音 |
| 片头 / 不循环 | `vlog_intro` | `bpm: auto` + `length` + `at`；收尾段落用长音和吊镲收住 |

## 常见的坑

- 只在 `harmony` 里写了和弦，却没有声部会弹它：至少要有一个 `comp`、`pad`、`arpeggio` 或 `strum` 声部。
- 换和弦的位置没有起音。comp 和 bassline 在延长（`-`）途中换和弦，会自动在新和弦上重新起音；但 strum 和写成 `.`（休止）的位置不会，新和弦要等到下一次起音才响。一小节两个和弦时，记得在第三拍写起音。
- 修改时整份重写乐谱：没改的部分会因为写法细节变化而跟着变。应该只改相关的那几行。
